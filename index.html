配置流程与操作说明

安全梯的核心是“订阅链接 + 标准客户端”。官网不托管安装包，以避免文件被替换。完成支付后，按下列步骤即可连接。整个过程强调核对来源、保存备份链接，以及按场景选节点。

  1. 确认套餐并保存订阅

    在套餐方案中选定基础版、旗舰版或团队版。支付成功后进入用户中心复制订阅 URL，建议同时记录到期日与流量额度。年付用户可一次导入、长期更新节点列表。

  2. 准备官方客户端

    Windows 常用 Clash 系或 v2rayN；macOS 可用 Clash Meta / Surge；iOS 使用 Shadowrocket、Stash 等；Android 使用 Clash Meta for Android。请一律从各软件开发者站点或系统应用商店获取，导入安全梯订阅即可，无需所谓“安全梯专属安装包”。

  3. 导入订阅并更新节点

    打开客户端的订阅或配置页面，粘贴安全梯提供的链接，执行更新。成功后会出现香港、日本、新加坡、美国等分组。先测延迟，再按用途选择：浏览与文档走普通中转，影视选解锁节点，游戏选 IPLC。

  4. 开启系统代理并验证

    将客户端设为系统代理或 TUN 模式，访问需要加速的站点确认连通。若某条线路异常，切换同区域备用节点即可。旗舰版与团队版用户遇到持续故障可通过优先工单反馈。

  5. 日常维护

    每周更新一次订阅以防节点变更。流量将尽或临近到期时在用户中心续费或升级。不要把订阅链接发到公开群组。更换设备时重新导入同一链接，并注意套餐设备台数上限。

常见问题

如何确认自己访问的是安全梯官方网站？

请通过书签固定本页，认准品牌名称「安全梯」与页面内的套餐、配置说明。官方只在本站公布订阅获取方式，不会以安装包或远控工具作为“加速器客户端”。若域名或页面结构与此明显不符，请停止输入账号。

安全梯支持哪些客户端，是否提供官网下载安装包？

支持主流 Clash、Shadowrocket、v2rayN 等兼容订阅协议的工具。安全梯不提供自行打包的安装文件，以避免被植入无关代码。正确做法是：在各客户端官方来源完成下载，再导入本站用户中心的订阅链接。

三个套餐的设备数和流量如何理解？

基础版每月 100GB、3 台同时在线；旗舰版 300GB、5 台；团队版 1000GB、20 台。同时在线指当前建立代理的设备数量，流量在套餐周期内累计，用尽后需等待重置或升级。年付仅影响结算优惠，不改变月度流量规则。

怎样按场景选择节点，能否解锁常见流媒体？

网页与资料检索用普通中转即可。Netflix、Disney+ 等请使用旗舰版或团队版中标注原生解锁的线路，并避免全局规则把国内站点也送出境外。游戏与实时语音优先 IPLC。若某一平台仍提示地区限制，可更换同区域其他解锁节点后再试。

导入订阅后无法连接或速度不稳怎么办？

依次检查：本地网络是否正常、系统时间是否准确、客户端是否已更新订阅、是否选中了可用节点、防火墙是否拦截。可切换协议或关闭再开启代理。持续异常时，旗舰版与团队版可通过优先工单提交日志截图，便于排查入口或出口问题。

团队版能否做企业定制，和个人套餐有何不同？

团队版已包含更高流量、更多设备和 VIP 带宽节点，并支持一定程度的路由定制。若需要独立入口、专属线路或对接内部网段，可通过客户经理在工单中说明需求。个人使用旗舰版通常已经覆盖流媒体与游戏；多人共用再考虑团队版更划算。
